# Jira Project Creation Screenshots

These screenshots document the Jira setup for the Patient Health Record Consent Management System.

1. `01_Jira_Epics_List.png` — Epic list: Consent Management, Provider Verification, Health Record Access, Audit and Compliance.
2. `02_Jira_Board.png` — Kanban board showing the project work.
3. `03_Jira_Backlog_Work_Items.png` — Backlog containing functional/non-functional requirements and user stories.
4. `04_Jira_User_Stories.png` — User stories for consent, provider verification, record access, audit events, and expired consents.
5. `05_Jira_Tasks.png` — Task-level breakdown such as selecting provider, setting scope/expiry, validating identity, authorization checks, record access, audit logging, and history.
