# MyProject_Healthcare_Consent_Management_System

**Individual Project — Problem Statement #13**  
**Healthcare & Telemedicine: Patient Health Record Consent Management System**

## Project purpose
A system for managing patient consent for access to health records. Patients can control which verified healthcare providers can access specific medical records, for how long, and can view or revoke access. The system also supports provider verification, controlled record access, auditability, and performance requirements.

## Selected architecture for the current draft
**Layered Architecture**

The current draft uses:
1. Presentation Layer
2. Business/Service Layer
3. Data Layer

The choice is based on clear separation of concerns, centralized enforcement of consent rules, auditability, and straightforward management of healthcare-record access.
