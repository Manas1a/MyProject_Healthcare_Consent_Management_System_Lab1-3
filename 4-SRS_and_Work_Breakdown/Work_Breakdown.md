# Work Breakdown Structure

1. Requirements
   - Identify functional requirements
   - Identify non-functional requirements
   - Prepare RTM

2. Architecture
   - Compare architectural styles
   - Select architecture
   - Identify components
   - Identify interfaces
   - Create component diagram
   - Write justification

3. Documentation
   - Prepare SRS
   - Prepare work breakdown

4. Implementation / Copilot
   - Generate or assist with code
   - Capture evidence

5. Testing
   - Execute test cases
   - Fix bugs / apply patch
   - Retest
   - Capture evidence
